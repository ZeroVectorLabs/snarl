# Levi's World

Source for the static site served at [levi69.org](https://levi69.org) via GitHub Pages.

## Structure

- `index.html` – home page
- `dekel/` – Dekel page and card images
- `events/` – events page
- `snarl/` – snarl page

## Deployment

Pushes to `main` are published automatically by GitHub Pages; the custom domain is set in `CNAME`.
